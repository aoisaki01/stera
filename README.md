# Stera

Modern web platform built with Next.js 16, React 19, TypeScript, and Firebase.

## Features

* Server and client component architecture on Next.js App Router
* Real-time cloud storage and database integration with Firebase SDK
* UI icons provided by Lucide React
* Responsive styling built on Tailwind CSS v4

## Tech Stack

* Next.js 16
* React 19
* TypeScript
* Firebase SDK
* Tailwind CSS v4
* Lucide React

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
